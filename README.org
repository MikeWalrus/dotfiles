* Arch Linux
[[file:localpkglist.txt]] and [[file:pkglist.txt]] are supposed to be lists of packages that are out of and in the Arch Linux repos respectively.

I use a pre-commit hook to generate them.
#+begin_src bash
#!/usr/bin/env bash
set -eo pipefail
pacman -Qqe > pkglist.txt
pacman -Sl aur | awk '/installed.$/{print $2;}' > localpkglist.txt
git add pkglist.txt localpkglist.txt
#+end_src
